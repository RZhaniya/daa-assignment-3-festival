# Assignment 3: Graph Algorithms for a Campus Festival

Implement DSU, Kruskal, Prim, Kosaraju SCC, DFS topological ordering and DAG shortest paths in one language: Java, Python, C++ or C#.

[English specification](docs/Assignment_3_EN.pdf) · [Задание на русском](docs/Assignment_3_RU.pdf)

## Work plan

1. Create your copy using **Use this template → Create a new repository**.

2. Select the language in submission.json and complete the corresponding Algorithms file.

3. Run **Actions → Public checks**, add student tests and complete ANALYSIS.md.

4. Submit the **commit URL** and the **successful Public checks run URL for that commit** in Moodle Online text, then click **Submit assignment**.

Give the instructor access to a private repository. The submitted commit will be assessed using additional tests and a review of the implementations and analysis.
