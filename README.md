# Assignment 3: Plan the Campus Festival

Connect festival places, choose inexpensive cables, identify circular dependencies, schedule preparation and find delivery routes. Complete six algorithms in **one** language: Java, Python, C++ or C#. The input/output framework and ready-made tests are provided.

## Your steps

1. Select **Use this template в†’ Create a new repository** and work in your own copy. A private copy must be accessible to your instructor.

2. Set language in `submission.json`: `Java`, `Python`, `Cpp` or `CSharp`. Complete the six TODO methods in your selected Algorithms file under `source/`. See the assignment for what each must do. Other language folders are alternatives.

3. Commit and push. Open **Actions в†’ Public checks**, enable Actions if asked and read the latest run. The tests run automatically after a push. TODO failures are expected until you implement the algorithms.

4. Add your examples and results under `tests/student/`; complete the short explanations and comparison in `ANALYSIS.md`. Push again and check that Public checks is green for the commit you will submit.

5. In Moodle Online text, submit the **exact commit URL** and the **successful Actions run URL for that commit**. Save and click Submit assignment; confirm Submitted for grading. No project upload or student ID is required. A changing main-branch link does not fix a version. If you revise before submissions close, update both links; contact the instructor if locked.

After the deadline, the instructor checks the submitted commit with separate deeper tests. Public checks provide preparation feedback. Keep your private repository accessible for checking. Later commits do not replace the commit submitted in Moodle.

[TESTING.md](TESTING.md) explains the optional local tools. [CONTRACTS.md](CONTRACTS.md) is the technical input/output reference. Student code belongs in the source folder of the selected language; helper source files may be added directly in that folder. Use standard collections, sorting and priority queues, but implement the required algorithms yourself rather than replacing them with an external algorithm library.
