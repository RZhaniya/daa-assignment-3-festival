# Assignment 3: подготовка фестиваля

Разработайте набор алгоритмов для связи площадок, поиска циклических зависимостей, планирования подготовки и доставки материалов. Реализуйте шесть алгоритмов на одном языке: Java, Python, C++ или C#.

**Дедлайн: 18 октября 2026 года, 23:59 (Asia/Qyzylorda, UTC+5).**

[Задание на русском](docs/Assignment_3_RU.pdf) · [Задание на английском](docs/Assignment_3_EN.pdf). Требования одинаковы.

## Начало работы

1. В GitHub нажмите **Use this template → Create a new repository**, выберите свой аккаунт и любое название. Можно использовать публичный или приватный репозиторий; при необходимости предоставьте преподавателю доступ к приватному.
2. Установите Git, Python 3.12+ и среду выбранного языка: JDK 17+, компилятор C++17 или .NET SDK 8. Python нужен для запуска инструментов на любом языке.
3. Склонируйте именно свою копию и перейдите в её папку:

```sh
git clone https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

4. В `submission.json` установите `language`: `Java`, `Python`, `Cpp` или `CSharp`. Реализуйте алгоритмы в папке `source/` выбранного языка. Дополнительные исходники размещайте непосредственно в ней. Сохраните работоспособность JSON-адаптеров.

## Реализация и проверка

```sh
python tools/run.py --setup
python tools/run.py --check
python tools/run.py --input examples/dsu.jsonl
python tools/check_submission.py
```

В Windows можно заменить `python` на `py -3`. По умолчанию язык берётся из `submission.json`; `--language` меняет его только для конкретного запуска. Setup проверяет сборку и обмен данными. Проверки алгоритмов на заготовке с TODO ожидаемо не проходят. Подробнее: [TESTING.md](TESTING.md).

Добавьте свои входные данные, ожидаемые и фактические результаты в `tests/student/`. Заполните `ANALYSIS.md` и `SUBMISSION.md`. После push в **Actions → Public checks** появятся результаты; если GitHub предложит, включите Actions в своей копии. Это обратная связь для подготовки, а не официальная оценка или доказательство авторства. Проверяйте программу и локально.

## Сдача в Moodle

1. Выполните проверки, изучите результаты, сделайте commit исходников, своих тестов и документов, затем push. Убедитесь, что `git status` не показывает изменений.
2. Создайте ZIP из закоммиченных файлов, подставив числовой ID студента:

```sh
python tools/package_submission.py --student-id YOUR_NUMERIC_STUDENT_ID
```

3. В Assignment 3 загрузите `.submission/Assignment3_<ID>.zip`. В **Online text** вставьте три строки из `.submission/Moodle_submission.txt`: ссылку на репозиторий, полный SHA коммита и язык.
4. Сохраните работу, нажмите **Submit assignment** и убедитесь, что до дедлайна появился статус **Submitted for grading**. Сохранённый черновик не считается завершённой сдачей. Сохраните подтверждение и ZIP.

ZIP включает исходники выбранного языка, `submission.json`, `ANALYSIS.md`, `SUBMISSION.md`, `README.md` и ваши тесты. Сборки, остальные языки, инструменты публичной проверки и тренировочные PDF не включаются. Созданные файлы игнорируются Git. Успешная упаковка сама по себе не означает, что алгоритмы готовы.

Для исправления до дедлайна сделайте новый commit и push, создайте новый ZIP и замените сдачу через доступные элементы Moodle. Если работа заблокирована, обратитесь к преподавателю до дедлайна. Изменения только на GitHub не обновляют ZIP в Moodle. После дедлайна преподаватель проверит загруженный снимок; своевременность определяется записью Moodle. Одобренное индивидуальное продление имеет приоритет.
