# Assignment 3: подготовка фестиваля

Соедините площадки, выберите недорогие кабели, найдите циклические зависимости, составьте план подготовки и маршруты доставки. Реализуйте шесть алгоритмов на **одном** языке: Java, Python, C++ или C#. Ввод, вывод и готовые тесты уже предоставлены.

Начните с [задания на русском](docs/Assignment_3_RU.pdf) или [на английском](docs/Assignment_3_EN.pdf). В них есть вступление, план работы, объяснение каждой части и примеры.

## Порядок работы

1. Нажмите **Use this template → Create a new repository** и работайте в своей копии. К приватной копии преподавателю нужен доступ.

2. В `submission.json` выберите language: `Java`, `Python`, `Cpp` или `CSharp`. Заполните шесть TODO в файле Algorithms своего языка под `source/`. Что должен делать каждый метод, объяснено в задании. Остальные языки — альтернативы.

3. Сделайте commit и push. Откройте **Actions → Public checks**, включите Actions при необходимости и изучите последний запуск. Готовые тесты запускаются после push автоматически. Пока алгоритмы не реализованы, ошибки TODO ожидаемы.

4. Добавьте свои примеры и результаты в `tests/student/`, заполните короткий анализ и сравнение в `ANALYSIS.md`. Сделайте новый push и убедитесь, что Public checks зелёный для сдаваемого коммита.

5. В Online text Moodle сдайте **URL конкретного коммита** и **URL успешного Actions этого коммита**. Сохраните, нажмите Submit assignment и проверьте Submitted for grading. Проект загружать и ID студента вводить не нужно. Изменяемая ссылка на main не фиксирует версию. При исправлении до закрытия приёма обновите обе ссылки; если работа заблокирована, обратитесь к преподавателю.

После дедлайна преподаватель проверит сданный коммит отдельными более глубокими тестами. Публичные тесты помогают подготовиться. Приватный репозиторий должен оставаться доступным преподавателю. Поздние коммиты не заменяют версию, сданную в Moodle.

[TESTING.md](TESTING.md) — необязательная локальная проверка. [CONTRACTS.md](CONTRACTS.md) — технический справочник полей входа/выхода. Код и вспомогательные исходники размещаются непосредственно в source выбранного языка. Стандартные коллекции, сортировки и очереди с приоритетом допустимы; требуемые алгоритмы реализуйте сами, без замены внешней библиотекой алгоритмов.

## Подготовка к квизу Assignment 3

[Вариант A](docs/A3_Practice_A_EN_RU.pdf) и [вариант B](docs/A3_Practice_B_EN_RU.pdf): по 30 вопросов на английском и русском, после вопросов идут ответы с объяснениями. Попробуйте решить один вариант за 30 минут и затем проверьте рассуждения. Это новые примеры тех же навыков, которые не входят в оцениваемый банк. Основной квиз на английском; Java-фрагменты используют простые массивы, циклы и арифметику, без проверки библиотечных API.
