# Assignment 3: Графовые алгоритмы для подготовки фестиваля

Реализуйте DSU, Краскала, Прима, SCC методом Косарайю, топологическую сортировку через DFS и кратчайшие пути в DAG на одном языке: Java, Python, C++ или C#.

[English specification](docs/Assignment_3_EN.pdf) · [Задание на русском](docs/Assignment_3_RU.pdf)

## Порядок работы

1. Создайте свою копию через **Use this template → Create a new repository**.

2. Выберите язык в submission.json и заполните соответствующий файл Algorithms.

3. Запустите **Actions → Public checks**, добавьте собственные тесты и заполните ANALYSIS.md.

4. В Online text Moodle укажите **URL коммита** и **URL успешного Public checks этого коммита**, затем нажмите **Submit assignment**.

Предоставьте преподавателю доступ к приватному репозиторию. Сданный коммит оценивается по дополнительным тестам, реализациям и анализу.
