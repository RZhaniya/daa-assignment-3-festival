# Assignment 3 — Graph Algorithms for a Campus Festival

Графовые алгоритмы для подготовки фестиваля. Реализуйте DSU, отдельные алгоритмы Краскала и Прима, SCC методом Косарайю, DFS-топологический порядок и кратчайшие пути в DAG на **одном** языке: Java, Python, C++ или C#. Java 17+ — основной язык силлабуса; действующий выбор четырёх языков для A3 сохраняется.

[English specification](docs/Assignment_3_EN.pdf) · [Задание на русском](docs/Assignment_3_RU.pdf)

## Порядок работы

1. Создайте репозиторий через **Use this template → Create a new repository**. Предоставьте преподавателю доступ, если репозиторий приватный.
2. Укажите `Java`, `Python`, `Cpp` или `CSharp` в поле `language` файла [submission.json](submission.json), затем реализуйте шесть методов в папке `source` выбранного языка.
3. Добавьте свои входы, ожидаемые и фактические результаты в `tests/student/`. Заполните [ANALYSIS.md](ANALYSIS.md) на английском: включите реальные вызовы восстановления маршрута и воспроизводимый benchmark Краскала–Прима.
4. Отправьте изменения на GitHub и получите успешный **Actions → Public checks** для этого коммита.
5. В Moodle **Online text** укажите **URL коммита** и **URL успешного Public checks того же SHA**, затем нажмите **Submit assignment**.

Соблюдайте даты и утверждённое индивидуальное продление в Moodle. Проверяется указанный коммит; приватный репозиторий должен оставаться доступным преподавателю.

[Точные контракты](CONTRACTS.md) · [Тестирование и среды](TESTING.md) · [Рубрика практики](RUBRIC.md) · [Уточнения к лекциям (English / Russian)](docs/Lecture_Clarifications_EN_RU.pdf)

A3 состоит из **50 баллов практики + 50 баллов квиза** и сохраняет вклад 20% во вторую аттестацию. Практика: **50 автоматических баллов**; квиз также оценивается автоматически из 50. Ручных баллов и устного восстановления нет. В рубрике приведены веса групп и порядок исправления дефекта проверки.

В исходном шаблоне намеренно оставлены TODO. Если setup проходит, а алгоритмические примеры падают до реализации методов, это ожидаемо. Public checks дают обратную связь; преподаватель также использует независимые проверки и изучает требуемые методы и анализ.

Соблюдайте AI-политику силлабуса: письменно раскройте инструменты и вклад, допустимую помощь с идеями/отладкой/предложениями кода и отвечайте за итоговую работу. В ANALYSIS.md опишите собственную проверку.
