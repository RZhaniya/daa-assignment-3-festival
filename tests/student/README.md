# Your own tests

Put your request files and short test notes here. A .jsonl file contains one complete JSON request per line. Run it from the repository root with:

`python tools/run.py --input tests/student/your_cases.jsonl`

Record expected and actual results and explain which mistake each test would expose. Include your own cases for disconnected graphs, repeated unions, cycles, tied answers and resetting state. The public examples are useful practice but do not replace your own tests. Do not copy expected results into actual results without running the program.

Russian instructions: сохраните здесь свои входные данные и результаты. Напишите, какую ошибку выявляет каждый тест. JSON-команды остаются на английском; объяснения можно писать по-русски.
