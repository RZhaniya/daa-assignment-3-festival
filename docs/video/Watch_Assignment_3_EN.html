How to use this lesson

Choose a chapter or watch in order. Pause at a changing graph and predict the next state before continuing. Follow the original edge IDs, not the order in which edges are examined. The Java fragments illustrate individual actions. Implement the complete methods yourself in your chosen language.

Use the assignment's CONTRACTS.md for the exact interfaces and output rules. Different valid forests, SCC labels, topological orders and tied shortest routes can be accepted. The benchmark numbers in the lesson are illustrative.
